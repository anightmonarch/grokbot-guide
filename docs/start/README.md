这一章带你在几天内把 Grok Bot 跑起来。顺序是：先知道它是什么，再装客户端并登录，然后给它建一个职责明确的 Bot，最后熟悉云电脑、本地执行和手机端。

## 1. 这一章覆盖什么

- 概念：Bot、云电脑、多 Bot 协作各自解决什么问题。
- 环境：桌面端安装、登录与首次引导。
- 资格：哪些订阅方案包含 Grok Bot。
- 第一个 Bot：怎么把职责和审批边界写清楚。
- 执行面：云电脑、接管、本地执行、手机端。

这五件事对应五个问题：它是什么、我有没有资格用、怎么装起来、怎么给它派活、它到底能碰哪些东西。前三个问题十分钟内能解决，后两个需要跑过几次真实任务才有体感。

## 2. 按这个顺序读

1. [Grok Bot 是什么](/start/what-is/) — 先建立整体印象，知道它和聊天助手的差别。
2. [订阅与资格](/start/plans/) — 确认账号能不能用，以及去哪里查官方说明。
3. [安装与登录](/start/install/) — 装客户端、完成登录与首次引导。
4. [创建第一个 Bot](/start/first-bot/) — 建一个职责窄的 Bot，把规矩写进描述。
5. [云电脑与接管](/start/computer/) — 理解任务实际跑在哪里，什么时候需要你接管。
6. [本地执行](/start/local-exec/) — 决定要不要让它碰你的本机。
7. [手机端](/start/mobile/) — 把查看和审批带到手机上。

## 3. 一个零风险的第一单

想先看看效果，又不想让它动任何外部系统，可以从一份文件开始。官方给出的五分钟样例是：附上一份文档，要求它用五条要点做总结，把日期、决定和未决问题单独列出来，每条注明出处，并且不要改动源文件。

这类任务不需要连接器，也不需要网页登录，不会产生对外动作。跑通之后，你手里就有了一个可以改写的模板：结果是什么、来源在哪里、哪些事不能做、要交回什么、什么时候必须先问你。
