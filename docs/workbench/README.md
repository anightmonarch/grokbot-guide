工作台讲的是把一次性的活变成可重复的流程：接什么应用、记住什么、什么时候自己跑，以及怎么让多个 Bot 分工。

## 1. 六个主题

1. [Connectors](/workbench/connectors/) — 用连接器接入外部应用。
2. [Skills](/workbench/skills/) — 把走通的做法存成技能。
3. [Routines](/workbench/routines/) — 用时间或事件触发流程。
4. [记忆](/workbench/memory/) — Bot 记住了什么。
5. [多 Bot 协作](/workbench/multi-bot/) — 群聊、@ 与交接。
6. [安全与审批](/workbench/security/) — 审批卡、Auto Review 与最小权限。
7. [设置总览](/workbench/settings/) — 通用 / 电脑 / 用量 / 更新；**电脑页有完整图文**。

## 2. 顺序建议

先用一次性任务把流程跑通，再存成 skill，最后才做成 routine。技能是「怎么做」，例程是「什么时候做」。

## 3. 共同的前提

所有 Bot 共用一台云电脑。屏幕分开，不等于权限分开。涉及发送、发布、购买、删除和改生产环境的动作，都留在审批后面。
