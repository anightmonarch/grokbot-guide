Grok Bot 的 **Settings** 管的是整机与账号级行为；单个 Bot 的名字、描述和通知在对话详情里改，不在这里。

## 1. 怎么打开

- 点侧边栏左下角的账号入口（头像 + 账号名），选 **Settings**。  
- 或按 `Cmd/Ctrl+,`。  
- 命令面板里也可以搜打开设置（快捷键总表见官方协作文档）。

没有独立的齿轮图标或系统「偏好设置」菜单项——入口就是账号菜单或快捷键。

## 3. Connect apps 不在 Settings 里

连接器与私有技能在侧边栏的 **Connect apps**（连接应用），不是设置对话框里的一页。安装、重连与 `@` 挂接见[Connectors](/workbench/connectors/)。
