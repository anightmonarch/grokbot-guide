本站提供 Grok Bot 中文实践手册，由一宿君维护。

## 1. 定位

- 收录的是可以核验的内容：官方文档写明的功能、界面标签和行为，以及可复用的个人实践做法。
- 页面顶部的核对日期标明内容对照的是哪一版官方文档。官方文档更新后，功能与标签可能变化，以官方文档为准。

## 2. 内容怎么来的

正文以 docs.x.ai 的官方文档为主要来源，每页开头用 `::: source` 列出用到的页面。个人实践会写明是「个人实践」，社区反馈会标为社区实践并给出出处。无法核实的内容不写进正文，只在源码里留一条备注。

## 3. Commit 日记

公开渠道有一个写作专栏叫 Commit 日记，记录 Grok Bot 的实践过程与复盘。那里写的是个人经验，不是操作手册；本站只把其中可核验、可复用的部分整理成文档。

## 4. 许可

本站的文字与代码以 MIT 协议发布。文中引用官方文档的部分，著作权归原作者所有。

## 5. 使用说明

产品功能与界面可能更新，请结合页面核对日期阅读。执行发送、支付、删除和本地操作前，请以官方文档和实际界面为准。
