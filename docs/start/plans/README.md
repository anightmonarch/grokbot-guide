本页只回答三个问题：哪种方案类型包含 Grok Bot、怎么把 SuperGrok 关联到 Cursor 账号、登录后怎么确认自己真的能用。价格与额度以官方页面为准，本页不写数字；核对日期见上方。

## 1. 官方列出的获取方式

- 付费个人 Cursor 方案与 Cursor Teams 方案包含 Grok Bot。
- 也可以把个人的 SuperGrok、SuperGrok Plus 或 SuperGrok Heavy 订阅关联到 Cursor 账号。
- The X Subscription 下的 Premium、Super、Ultra 包含 Grok Bot。

换句话说，Grok Bot 的使用权跟着你的 Cursor 账号走：先有符合条件的订阅或关联，再谈安装。判断自己属于哪种情况，最快的办法是打开 Cursor 控制台看当前订阅；另一条路是登录 grok.com 看账户状态。

## 2. 方案类型对照

| 方案类型 | 是否含 Grok Bot | 官方说明 |
| --- | --- | --- |
| The X Subscription · Plus | 不含 | 官方说明中该档位不包含 Grok Bot；要使用需要选 Premium 或更高 |
| The X Subscription · Premium | 含 | 订阅后即可使用 |
| The X Subscription · Super | 含 | 官方说明中包含 Grok Bot，并提供更大的共享周额度 |
| The X Subscription · Ultra | 含 | 官方说明中包含 Grok Bot，并提供更大的共享周额度 |
| 付费个人 Cursor 方案 | 含 | 官方说明为「每个付费个人 Cursor 方案」 |
| Cursor Teams · 自助购买席位 | 含 | 官方说明自助购买的 Teams Standard 与 Premium 席位包含 Grok Bot |
| Cursor Enterprise | 逐步开放 | 可用范围与管理员控制因组织而异，需联系 Cursor 客户团队确认 |
| SuperGrok / SuperGrok Plus / SuperGrok Heavy | 关联后可用 | 关联到 Cursor 账号之后生效 |

## 3. 额度是怎么算的

- The X Subscription 下，Grok、Grok Bot 与 Cursor 共用同一个周额度池；订阅包含每周用量，符合条件的账号可以另行按用量付费。
- 如果你同时有 Cursor 与 SuperGrok 订阅，Grok Bot 使用其中额度更高的那一个。
- The X Subscription 下的账户合并不可撤销，Support 也不能替你撤销；不切换的话，当前方案继续有效。新客户直接开始使用 The X Subscription。

## 4. 怎么确认账号可用

登录 Grok Bot 之后按顺序确认三件事：

1. 侧边栏能正常打开 Bot 列表——说明账号已经通过认证并有权限。
2. 如果侧边栏提示没有权限或一直转圈，按官方排障处理：用欢迎页的 **Sign in**，或从 Settings 用 **Sign In with Cursor** 重新走一次，并在浏览器里确认登录成功。
3. 所在组织要求 SSO 时，走组织正常的登录流程，不要改用另一个个人账号。

权限来自 SuperGrok 订阅时，登录过程中应用会主动提示关联，关联完成后状态会刷新。

## 5. 关联 SuperGrok 的步骤

1. 用你的 Cursor 账号登录 Grok Bot。
2. 桌面端打开 **Settings → Usage & Billing**，点 **Link SuperGrok Heavy**。这个标签名对应你账号适用的 SuperGrok 档位，官方文档里写的就是这个措辞。
3. 在浏览器里完成关联并授权。
4. 回到应用确认状态已更新。

手机端的路径不同：访问页先选 **Link Grok Account**，在浏览器里完成关联，再选 **Finished Linking? Refresh My Status**。

## 6. 在哪里看用量

- 切换前：打开 Cursor 控制台 [cursor.com/dashboard](https://cursor.com/dashboard) 查看。
- 切换后：在 grok.com 控制台 [grok.com/dashboard](https://grok.com/dashboard) 打开 **Usage**。
- 应用内：桌面端 **Settings → Usage & Billing**，或者访问页上的用量入口。

![设置 · 用量与账单](/settings/usage-tab.png)

## 7. 切换到 The X Subscription 会发生什么

The X Subscription 给一个工作区一份账单，覆盖 Cursor 和 Grok；加上个人 X 账号后还包含 X 的权益。想合并哪些账号、可合并的条件，见官方 [Unification eligibility](https://docs.x.ai/x-subscription/eligibility)。

切换时的账务规则：

- 选一个覆盖 Cursor 与 Grok 的档位，旧的在结账时取消，未使用的时间按比例退回。
- 通过 Apple App Store 买的 Cursor 订阅官方无法取消，需要自己在 Apple 那边取消。
- 通过 Apple App Store 买的 Grok、Grok Bot 或 X Premium 由官方取消并向 Apple 申请退款，退多少由 Apple 决定。
- 通过 Google Play 买的，切换后要去 Google Play 的订阅里看一眼，如果还在自动续订就取消掉。

## 8. 团队与企业

自助购买的 Cursor Teams 席位包含 Grok Bot。企业方案正在逐步开放，可用范围与管理员控制因组织而异，需要联系你的 Cursor 客户团队确认当前的开放状态。团队里由管理员决定 Auto Review 与本地执行等策略上限；团队策略更严时，按团队的来。
