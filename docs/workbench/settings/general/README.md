**通用（General）** 管账号与外观等全局项。下面按真机界面讲解；插图来自站长桌面客户端截图。

![Grok Bot 设置 · 通用页账户、外观与订阅入口](/settings/general-tab.png)

上图可见左侧页签：**通用**（当前）、**电脑**、**用量与账单**、**更新**。右侧自上而下大致是：顶部订阅入口卡片、**账户**、**外观**。

## 1. 左侧页签

设置弹窗左侧固定四项（与[设置 · 电脑](/workbench/settings/computer/)所见一致）：

| 页签 | 去哪 |
| --- | --- |
| **通用** | 本页 |
| **电脑** | [设置 · 电脑](/workbench/settings/computer/) |
| **用量与账单** | [设置 · 用量与账单](/workbench/settings/usage/) |
| **更新** | [设置 · 更新](/workbench/settings/updates/) |

## 2. 账户

**账户**区展示当前登录身份：

- 登录名（截图示例为用户显示名） 
- 邮箱（旁有复制图标） 
- **添加账户**：再挂一个账号（多账号切换时用） 
- **退出登录**：退出当前账号 

账号切换 / 登出会影响本机会话与已连接应用；退出前确认没有正在跑、依赖本机授权的任务。

## 3. 外观

截图中 **外观** 有三项下拉（以客户端为准）：

| 控件 | 截图示例取值 | 说明 |
| --- | --- | --- |
| **主题** | 跟随系统 | 也可选浅色 / 深色一类选项（以客户端列表为准） |
| **强调色** | Bot 颜色 | 界面强调色；截图当前选「Bot 颜色」 |
| **语言** | 跟随系统 | 可改为跟随系统或指定语言（含简体中文等） |

改语言后若部分文案仍英中混排，以当前客户端版本为准；对照官方文档时可用英文标签。

## 4. 顶部订阅入口（界面可见）

通用页顶部有一块订阅相关卡片（截图文案大意：统一订阅获取 Grok / Cursor / X、共享用量池；已订阅产品可合并）。这是**界面上的入口**，不是本站的推销——是否出现、文案与按钮（如「开始使用」）随账号与客户端版本变化。

额度、价格与资格请看[订阅与资格](/start/plans/)和[设置 · 用量与账单](/workbench/settings/usage/)；本站不写具体数字。

## 5. 截图未见、暂不展开

以下控件在**本张通用页截图中未见**，官方文档或其它版本可能另有入口，此处不编造：

- 拼写检查、麦克风、硬件加速、安全密钥等 
- 时区 / Bot 排程相关项（若你客户端有，以本机为准） 
- Auto-review 规则管理（审批相关仍见[安全与审批](/workbench/security/)；本机执行主界面在[设置 · 电脑](/workbench/settings/computer/)） 

## 你要检查什么

- 登录名与邮箱是否为当前要用的账号；多账号时先确认再操作。 
- 主题 / 语言是否符合习惯（跟随系统还是固定）。 
- 顶部订阅卡片只当入口；用量细节去「用量与账单」或官方订阅页。
