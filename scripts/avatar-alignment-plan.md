- 用户目标：全站 Logo、头像及动态效果对齐 `https://x.ai/bot`，布局、字体、按钮保持现状。

- 页面组件调用 `BotMark` 的 `color / shape / size / animated / hoverTarget / label` 接口。保留调用契约与尺寸。

- TDD 仅用于上述 Seam 的关键行为；不为样式常量编写镜像测试。

- `node --test scripts/avatar-contract.test.mjs`：2 项通过。覆盖全部 7 种公开 shape、每实例独立推进、12 秒跨轨道帧无非法数值、静止帧稳定、SSR 图形 ID 不冲突。
- `pnpm docs:build`：成功，渲染 52 页；构建耗时 1.44 秒。存在 slimsearch 的 `worker/dev.js` 构建警告，未阻断构建。

- 官方数据来源、原始 SHA-256、尺寸公式及本站角色映射见 `docs/.vuepress/theme/botmark/SOURCES.md`。
